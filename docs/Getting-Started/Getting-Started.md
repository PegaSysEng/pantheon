# Getting Started

You can get started with Pantheon by:
* Starting a node as described in [Starting Pantheon](Starting-Pantheon)
* Running from the [Pantheon docker image](Run-Docker-Image)
* Using the [Private Network Quickstart](Private-Network-Quickstart) 

To run a single node to connect the Ethereum mainnet or a public testnet, running from the Pantheon [docker image](Run-Docker-Image) or [installing the packaged binaries](Install-Binaries) is the fastest way to get started. 

To run a private network on which you can make JSON-RPC requests and send transactions, or explore Pantheon and Ethereum networks, the [Private Network Quickstart](Private-Network-Quickstart) runs a private network of Pantheon nodes in a Docker container.
