# Creating and Sending Private Transactions 

The [EEA JavaScript library](https://github.com/PegaSysEng/eeajs) is provided to create and send signed 
RLP-encoded private transactions. 

!!! note
    Private transactions are either contract creation or <what is this called> transactions. 
    Ether transfers are not supported as private transactions. 
    
1. Clone the library: 

```bash
git clone https://github.com/PegaSysEng/eeajs.git
```

2. Change into the `eeajs` directory:

```bash
cd eeajs
```

3. Install the library: 

```bash
npm install 
```
